# Thomack Legal Nurse Consulting

Static one-page website for Katy Thomack, RN, MSN, CLNC.

- `index.html` – page content
- `styles.css` – styles
- `images/` – headshot, NACLNC seal, favicon

Hosted on Netlify at https://thomacklnc.com. Every push to `main` is published automatically (no build step; the repo root is the publish directory).
